# DeepLabCut environment for tracking new videos with the bundled network.
#
#   uv venv .venv-dlc --python 3.10
#   uv pip install --python .venv-dlc -r requirements-dlc.txt
#
# Leave the interface's "DeepLabCut environment" field blank and the tool finds
# this folder on its own. No conda needed; environment-dlc.yml is still there if
# you would rather use conda.
#
# Why 3.10 and why these pins: the bundled snapshot is a TensorFlow ResNet-50,
# so it needs the TensorFlow generation of DeepLabCut (2.3.x). TensorFlow 2.10
# is the last release supporting Windows GPU, and it caps Python at 3.10 and
# NumPy at 1.x. tensorpack and tf-slim are imported by deeplabcut but missing
# from its wheel metadata, so they are named here explicitly.
#
# torch is a hard dependency of deeplabcut 2.3 and is not used by this tool.
# The CPU build keeps it near 200 MB instead of several GB; install with
#   --extra-index-url https://download.pytorch.org/whl/cpu --index-strategy unsafe-best-match
# or drop the "+cpu" pin below to let pip choose.
