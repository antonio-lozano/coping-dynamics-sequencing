Reproduce

Three commands, identical bytes

The locked uv environment installs the recorded Python and exact dependency versions; conda and pip routes ship too.

# install the locked environment
uv sync --locked

# verify the shipped artifacts against MANIFEST.csv
uv run python scripts/check_reproducibility.py

# rebuild every figure, table, report and the manifest — the tree ends clean
uv run python scripts/run_all.py

Hash manifest

MANIFEST.csv records a SHA-256 for all 558 artifacts. A rebuild that changes any byte fails the check; the repository referees itself.

Statistics fitted once

Every model is fitted in one place and exported; scripts/check_manuscript.py pins each statistic quoted in the manuscript to the shipped report.

Continuous verification

CI executes the science: locked installs, the full checker and test suite on Ubuntu and Windows, plus the companion tool's own tests.

Companion tool

Behavior classifier

A self-contained DeepLabCut-based freezing and seven-behavior classifier ships under tools/behavior_dlc_classifier/ with the trained tracking networks — including the iteration behind every published prediction — demo videos, its own test suite, and a step-by-step guide, so new videos can be tracked and classified without training anything.
