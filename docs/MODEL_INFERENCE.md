# Model Training and Inference (XGBoost)

This repo provides a reusable workflow for training a behavior classifier from DLC tracking data, applying it to new datasets, and generating lightweight QC plots.

## 0) Map raw AYA DLC to JEN schema (optional, for AYA data)

If your input is raw AYA DLC output (`.h5` or `.csv`), map it first to JEN-style columns.

PowerShell:

```powershell
python scripts/preprocessing/map_aya_to_jen.py `
  --input-dir D:\NINDATA\Aya_behavior\encoded-20260131T123011Z-3-001\encoded `
  --dataset-id matched_dlc_aya_to_jen `
  --pattern *_filtered.h5 `
  --fps-default 25
```

Outputs are written to:

`data/to_predict/<dataset_id>/`

Files:
- `*_matched_to_jen.csv`
- `fps_manifest.csv` (template with `recording,fps,source_file`)
- `mapping_report.json` (mapping and missing-bodypart report)

Notes:
- Ambiguous duplicate targets (`H2R`, `H2L`, `B1*`, `B3*`) are `NaN` by default to avoid artificial zero-distance geometry.
- `.h5` input requires PyTables (`pip install tables`).

## 1) Train and save a model

Run from repo root:

```powershell
python scripts/analysis/train_behavior_xgb.py `
  --dlc-dir data/CSVs_all `
  --results-clusters-pkl data/processed/new_results_clusters.pkl `
  --index-csv data/metadata/index.csv `
  --model-version 2026-02-10_baseline_v1
```

Quick smoke-test mode:

```powershell
python scripts/analysis/train_behavior_xgb.py --quick --model-version smoke_test_v1
```

Artifacts are saved to:

`results/model_training/models/xgb_behavior/<model_version>/`

Files:
- `model.json` (primary portable model)
- `model.pkl` (Python convenience artifact)
- `metadata.json` (feature schema, labels, training context)
- `cv_metrics.json` (cross-validation metrics)

## 2) Predict on new DLC data

Place new data in:

`data/to_predict/<dataset_id>/`

Run:

```powershell
python scripts/analysis/predict_behavior_xgb.py `
  --model-dir results/model_training/models/xgb_behavior/2026-02-10_baseline_v1 `
  --input-dir data/to_predict/my_new_cohort `
  --dataset-id my_new_cohort
```

Optional CSV selector:

```powershell
python scripts/analysis/predict_behavior_xgb.py ... --glob "*DLC*.csv"
```

Outputs:

`results/predictions/<dataset_id>/<model_version>/`

Files:
- `predictions_frame.parquet`
- `predictions_frame.csv`
- `predictions_summary.csv`

Prediction policy:
- Class = argmax probability (`pred_class`)
- Confidence = max probability (`pred_confidence`)
- Per-class probabilities in `p_<class>` columns

## 3) Visualize prediction QC

```powershell
python scripts/analysis/visualize_behavior_predictions.py `
  --predictions-dir results/predictions/my_new_cohort/2026-02-10_baseline_v1
```

Output:

`results/predictions/<dataset_id>/<model_version>/figures/`

Files:
- `prediction_qc.png`
- `prediction_qc.pdf`

QC panels:
- Class proportions per recording
- Prediction timeline for top recordings
- Confidence histogram
- Rolling confidence traces

Video overlays (also generated by default):
- MP4 per recording under `figures/videos/`
- Black background, white thick skeleton lines, colored bodypart points
- Predicted behavior text + confidence overlay
- Default duration: 10 seconds
- Default size: 512 x 512

Optional controls:
```powershell
python scripts/analysis/visualize_behavior_predictions.py `
  --predictions-dir results/predictions/my_new_cohort/2026-02-10_baseline_v1 `
  --video-seconds 10 `
  --video-size 512 `
  --video-fps 25 `
  --line-thickness 4
```

## 4) End-to-end smoke test (synthetic data)

```powershell
python scripts/analysis/smoke_test_xgb_workflow.py
```

This validates:
- Training artifact generation (`model.json`, `model.pkl`, `metadata.json`, `cv_metrics.json`)
- Inference outputs (`predictions_frame.parquet`, `predictions_frame.csv`, `predictions_summary.csv`)
- Feature-schema stability via strict reindexing
- Failure modes (missing model dir, empty input dir)
- QC figure generation
