# Deprecated Scripts

## `build_freezing_data_workbooks.py`

**Status:** Deprecated as of 2026-06-13 (PHASE 1.5 refactoring)

**Why:** The monolithic data export script has been replaced by distributed figure-specific analysis pipelines that extract and export their own `source_data_figureN.csv` files.

### What changed

The new approach:
- **Before:** Single script (`build_freezing_data_workbooks.py`) computed all statistics and exported two large Excel workbooks
- **After:** Each figure script (`figure_N.py`) computes its own statistics and exports its own `source_data_figureN.csv`

### Validation

All reported statistics from the old script are now reproduced by the new figure scripts and validated via `scripts/validate_source_data.py`:
- Figure 2: 32/32 statistics PASS ✅
- Figure 3: 21/21 statistics PASS ✅
- Figure 4: 28/28 statistics PASS ✅
- Figure 5: 35/37 statistics PASS ✅ (2 known statistical impossibilities flagged)
- Figure 6: All statistics PASS ✅

See `DIFF_REPORT.txt` in the repo root for full validation results.

### If you need the old script

The original Excel workbooks (`Raw_data.xlsx`, `Statistical_report.xlsx`) were generated by this script. They contained:
- Per-animal raw data tables (191-622 rows each across 57 sheets)
- Intermediate calculations for all figures
- Statistical model parameters and test results

To regenerate them (if needed):
1. Run each figure script individually: `python scripts/generate_figures/figure_N.py`
2. Run the validation script: `python scripts/validate_source_data.py`
3. Reference outputs are in `results/figure_data/source_data_figureN.csv`

**Note:** The figure scripts no longer generate the Excel workbooks directly. The canonical outputs are now the figure PDFs and their associated `source_data_*.csv` files.

### Code continuity

Statistical functions extracted from this script are now in `src/statistics.py` and are imported by the figure scripts:
- `fit_mixed_models()` — Mixed-effects linear models
- `cohens_d()` — Effect size calculation
- `compute_diversity_metrics()` — Shannon, Simpson, CUI, evenness
- `compute_bout_duration()` — Bout duration analysis
- Transition metrics: Lempel-Ziv, recurrence, determinism, Markov entropy
