# Results

Generated outputs are separated by role.

- `source_data/`: manuscript figure source-data CSVs for Figures 2-6.
- `statistics/`: model/statistical CSV outputs and manuscript Results text audit.
- `intermediate/`: helper tables and non-canonical figure renders used for audit.
- `models/`: trained model artifacts, including the Figure 7 behavior classifier.

Canonical manuscript figure exports live in `figures/`, not here.
