Canonical manuscript figures.

Each figureN.{pdf,svg,png} is regenerated by the matching script in
scripts/generate_figures/ (see the table in the repo README). Supporting
tables, audits, and intermediate renders are written to figures/data/.

Figure 1 is not included: it is a hand-made schematic with no repo generator.

Files:
  figure2.*                -> figure_2_validation.py
  figure3.*                -> figure_3_behavior_clusters.py
  figure4.*                -> figure_4_diversity_dynamics.py
  figure5.*                -> figure_5_resilience_dynamics.py
  figure6.*                -> figure_6_resilience_diversity.py
  supplementary_figure3.*  -> supplementary_figure_3_distances.py

Regenerate everything with:
  python scripts/run_all_figures.py
