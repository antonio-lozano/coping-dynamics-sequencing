Canonical manuscript figures.

Data-derived figures are regenerated by the matching scripts in
scripts/generate_figures/. Supporting tables and intermediate renders are
written to results/source_data/, results/statistics/, and results/intermediate/.

Figure 1 is a hand-made schematic with no repo generator. Figure 7 is a supplied
assembled manuscript figure and is not regenerated here.

Files:
  figure2.*                -> figure_2_validation.py
  figure3.*                -> figure_3_behavior_clusters.py
  figure4.*                -> figure_4_diversity_dynamics.py
  figure5.*                -> figure_5_resilience_dynamics.py
  figure6.*                -> figure_6_resilience_diversity.py
  figure7.*                -> supplied assembled manuscript figure
  supplementary_figure1.*  -> supplementary_figure_1_tracking_clusters.py
  supplementary_figure3.*  -> supplementary_figure_3_distances.py

  python scripts/run_all_figures.py
