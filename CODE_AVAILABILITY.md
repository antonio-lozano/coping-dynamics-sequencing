# Code Availability

All custom analysis code needed to regenerate the data-derived figures and
statistical outputs is included in this repository.

Primary entry points:

- `scripts/run_all_figures.py`
- `scripts/build_statistical_report.py`
- `scripts/check_reproducibility.py`
- `scripts/update_manifest.py`

Figure-specific scripts live in `scripts/generate_figures/`. Derived-table
scripts live in `scripts/derive_tables/`. Shared analysis utilities live in
`src/`.

For publication, cite the archived release DOI for this repository once it is
available.
